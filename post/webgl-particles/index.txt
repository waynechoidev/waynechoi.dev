19:T5ad,<p>I allocated two position buffers and used one buffer to calculate the positions, while drawing the screen with the other buffer. Whenever a new frame is initiated, I swapped the two buffers.</p>
<p>When utilizing GPGPU, like calculating the positions, in WebGL, there are typically two main methods: using the transform feedback functionality to store output values from the vertex shader into a buffer, or performing computations in the fragment shader using pixel data from textures. I opted for the former method.</p>
<p>While WebGPU supports compute shaders explicitly designed for GPGPU tasks, I chose to stick with WebGL due to my unfamiliarity with the new shader languages associated with WebGPU. (WebGL2 also introduced experimental support for compute shaders, but it seems this feature is no longer available, possibly due to the emergence of WebGPU.)</p>
<p>I referred to the code provided in <a href="https://webgl2fundamentals.org/webgl/lessons/webgl-gpgpu.html" class="md-link" target="_blank" rel="noopener noreferrer">this example</a>. To enhance code clarity and encapsulate the pipeline, I restructured and re-wrote the logic in a type-safe manner.</p>
