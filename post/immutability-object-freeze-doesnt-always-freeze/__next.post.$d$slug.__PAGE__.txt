12:T3757,<h3>Immutability series</h3>
<ol>
<li><strong>Object.freeze() doesn't always freeze</strong></li>
<li><a href="/post/immutability-immutable-js-pros-and-cons" class="md-link">Immutable.js, pros and cons</a></li>
</ol>
<hr />
<p>Immutability in JavaScript is getting more attention, while functional programming paradigm is on the rise. One of the important features of functional programming is that it has no side-effect.</p>
<p>A side effect is any application state change that is observable outside the called function other than its return value. It cause more problems by concurrency in an application. JavaScript is single thread language though, execution environment (browser and node.js) process various task at the same time. To avoid side effects, we need to keep the state outside the function immutable.</p>
<p>We can declare and assign immutable primitive variable with 'const' keyword, and keep properties of an object with 'Object.freeze()' method. The freeze method, however, does not always make objects immutable.</p>
<p>In this post, I would like to explain why 'Object.freeze()' method is not complete way to make an object immutable, and to illustrate this, I need to deal with data type of JavaScript first.</p>
<hr />
<h2>Data type of JavaScript</h2>
<p>JavaScript has 2 kinds of data types. One is primitive, and other is reference. Reference type is object which including array and function, and primitive type values are below.</p>
<ul>
<li>string</li>
<li>number</li>
<li>bigint</li>
<li>boolean</li>
<li>undefined</li>
<li>symbol</li>
<li>null</li>
</ul>
<hr />

<p>I declared a variable p1 and assigned number 1 to p1. Number 1 was not assigned to p1 directly, but allocated to memory first, and the memory address of number 1 is assigned to p1. Let's suppose the address of number 1 is '1000'. (All of memory address in this post is hypothetical to help understand memory allocation of JavaScript)</p>
<p>I declared new variable p2, and assigned number 1 to p2. The same memory address, '1000', was assigned to p2. Number 1 is primitive type data, and immutable.</p>
<p>And I reassigned number 2 to p1. At this time, number 1 in the memory '1000' won't be changed. Number 2 is allocated to the other space of memory, and its address '1001' is assigned to p1. (I would not deal with garbage collection to free memory in this post)</p>
<hr />

<pre><code class="hljs language-js"><span class="hljs-keyword">let</span> o1 = { <span class="hljs-attr">name</span>: <span class="hljs-string">"choi"</span> }; <span class="hljs-comment">// 2000</span>

<p>Object is basically mutable. If I declare two variables, and assigned objects which have same keys and values to those variables, two different memory addresses are assigned to each ones. Object is reference type data.</p>
<hr />
<h2>Copy</h2>
<pre><code class="hljs language-js"><span class="hljs-keyword">let</span> p1 = <span class="hljs-number">1</span>;
<span class="hljs-keyword">let</span> p2 = p1;

<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(p1); <span class="hljs-comment">// 1</span>
<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(p2); <span class="hljs-comment">// 1</span>

p1 = <span class="hljs-number">2</span>;

<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(p1); <span class="hljs-comment">// 2</span>
<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(p2); <span class="hljs-comment">// 1</span></code></pre><p>It is simple to copy primitive type data. Primitive type data is immutable, so if I copied then changed one data, it doesn't affect the other one.</p>
<hr />
<pre><code class="hljs language-js"><span class="hljs-keyword">let</span> o1 = { <span class="hljs-attr">name</span>: <span class="hljs-string">"choi"</span> };
<span class="hljs-keyword">let</span> o2 = o1;

<p>It, however, does work in different way for an object to copy. I assigned one variable, o1, which is assigned an object, to other variable, o2. I changed one of them, then it affects other variables as well. Object is reference type value, so both variable reference same object with same memory address.</p>
<hr />
<pre><code class="hljs language-js"><span class="hljs-keyword">let</span> o1 = { <span class="hljs-attr">name</span>: <span class="hljs-string">"choi"</span> };

<p>If we did not mean to change the property of the original object, it could cause serious errors of an application. To keep the o1 object immutable, we can use Object.assign() to copy an object. (If it is an array, we can use Array.concat() as well.)</p>
<hr />
<h2>Object.freeze()</h2>
<pre><code class="hljs language-js"><span class="hljs-keyword">let</span> o1 = { <span class="hljs-attr">name</span>: <span class="hljs-string">"choi"</span> };
<span class="hljs-title class_">Object</span>.<span class="hljs-title function_">freeze</span>(o1);

o1.<span class="hljs-property">name</span> = <span class="hljs-string">"kim"</span>;
o1.<span class="hljs-property">age</span> = <span class="hljs-number">30</span>; <span class="hljs-comment">// even cannot add new properties</span>

<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(o1); <span class="hljs-comment">// { name: "choi" }</span></code></pre><p>Finally we reached the freeze method. It freeze all properties of an object. we can block to change the original object from the very beginning with this method.</p>
<hr />
<h2>Const vs Freeze</h2>
<pre><code class="hljs language-js"><span class="hljs-keyword">let</span> o1 = { <span class="hljs-attr">name</span>: <span class="hljs-string">"choi"</span> };
<span class="hljs-title class_">Object</span>.<span class="hljs-title function_">freeze</span>(o1);

<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(o1); <span class="hljs-comment">// { name: "choi" };</span>

o1 = <span class="hljs-string">"hello world"</span>;

<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(o1); <span class="hljs-comment">// hello world</span>

<span class="hljs-keyword">const</span> o2 = { <span class="hljs-attr">name</span>: <span class="hljs-string">"choi"</span> };

o2 = <span class="hljs-string">"hello world"</span>; <span class="hljs-comment">// Uncaught TypeError: Assignment to constant variable.</span></code></pre><p>Const keyword is for immutable reference, and the freeze method is for immutable value. I declared variable o1 with let keyword and assigned an object to it. Then I freezed it.
I can still reassign other value to o1.
But if I make same variable o2 but with const keyword, I cannot reassign, even though I wouldn't freeze.</p>
<hr />
<h2>Cannot freeze Nested Object</h2>
<pre><code class="hljs language-js"><span class="hljs-keyword">let</span> o1 = { <span class="hljs-attr">name</span>: <span class="hljs-string">"choi"</span>, <span class="hljs-attr">occupation</span>: { <span class="hljs-attr">job</span>: <span class="hljs-string">"boat builder"</span> } };
<span class="hljs-title class_">Object</span>.<span class="hljs-title function_">freeze</span>(o1);

o1.<span class="hljs-property">name</span> = kim;
o1.<span class="hljs-property">occupation</span>.<span class="hljs-property">job</span> = <span class="hljs-string">"software engineer"</span>;

<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(o1); <span class="hljs-comment">// { name : "choi", occupation : { job : "software engineer"}}</span>
<span class="hljs-comment">// name hasn't changed, but job has</span>

<span class="hljs-keyword">let</span> o2 = <span class="hljs-title class_">Object</span>.<span class="hljs-title function_">assign</span>({}, o1);
o2.<span class="hljs-property">name</span> = <span class="hljs-string">"kim"</span>;
o2.<span class="hljs-property">occupation</span>.<span class="hljs-property">job</span> = <span class="hljs-string">"chef"</span>;

<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(o1); <span class="hljs-comment">// { name : "choi", occupation : { job : "chef"}}</span>
<span class="hljs-variable language_">console</span>.<span class="hljs-title function_">log</span>(o2); <span class="hljs-comment">// { name : "kim", occupation : { job : "chef"}}</span></code></pre><p>If values of one or multiple properties are reference type, aka nested object, both assign and freeze methods can not keep the original object immutable when cloning. They are called shallow freeze and clone.</p>
<hr />
<pre><code class="hljs language-js"><span class="hljs-keyword">function</span> <span class="hljs-title function_">deepFreeze</span>(<span class="hljs-params">object</span>) {
  <span class="hljs-keyword">var</span> propNames = <span class="hljs-title class_">Object</span>.<span class="hljs-title function_">getOwnPropertyNames</span>(object);

  <span class="hljs-keyword">for</span> (<span class="hljs-keyword">let</span> name <span class="hljs-keyword">of</span> propNames) {
    <span class="hljs-keyword">let</span> value = object[name];
    object[name] =
      value &amp;&amp; <span class="hljs-keyword">typeof</span> value === <span class="hljs-string">"object"</span> ? <span class="hljs-title function_">deepFreeze</span>(value) : value;
  }

  <span class="hljs-keyword">return</span> <span class="hljs-title class_">Object</span>.<span class="hljs-title function_">freeze</span>(object);
}</code></pre><p>If an object is nested with only one layer, we can freeze each properties with reference type value. It, however, is not easy to freeze all layers when the object is nested much deeper.</p>
<p>We can implement a function to deep freeze an object with recursion, or can use a library to support immutable data structure like immutable.js.</p>
