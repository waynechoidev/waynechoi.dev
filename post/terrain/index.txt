fn <span class="hljs-title function_">hash22</span>(<span class="hljs-attr">p</span>: vec2&lt;f32&gt;, <span class="hljs-attr">mat</span>: mat2x2&lt;f32&gt;, <span class="hljs-attr">scale</span>: f32) -&gt; vec2&lt;f32&gt; {

fn <span class="hljs-title function_">noise_sum</span>(<span class="hljs-attr">p</span>: vec2&lt;f32&gt;, <span class="hljs-attr">mat</span>: mat2x2&lt;f32&gt;, <span class="hljs-attr">scale</span>: f32) -&gt; f32 {
    <span class="hljs-keyword">var</span> p_scaled = p * <span class="hljs-number">4.0</span>;
    <span class="hljs-keyword">var</span> a = <span class="hljs-number">1.0</span>;
    <span class="hljs-keyword">var</span> r = <span class="hljs-number">0.0</span>;
    <span class="hljs-keyword">var</span> s = <span class="hljs-number">0.0</span>;

    <span class="hljs-keyword">for</span> (<span class="hljs-keyword">var</span> i = <span class="hljs-number">0</span>; i &lt; <span class="hljs-number">5</span>; i = i + <span class="hljs-number">1</span>) {
        r = r + a * <span class="hljs-title function_">perlin_noise</span>(p_scaled, mat, scale);
        s = s + a;
        p_scaled = p_scaled * <span class="hljs-number">2.0</span>;
        a = a * <span class="hljs-number">0.5</span>;
    }

    <span class="hljs-keyword">return</span> r / s;
}</code></pre><p>Perlin noise is a noise function designed to model randomness as seen in nature. Unlike simple random values, it uses gradient vectors at each point in space to create continuous and smooth noise patterns. This approach allows for more natural and consistent randomness.</p>
<p>In this code, two channels of Perlin noise are generated and stored in a single texture. These channels are used to create the terrain's height and color. By using different constants, the intention is to achieve a more diverse result.</p>
<p>The random function used here is not truly random but pseudorandom. By adding a uniform "progress" value based on the UV coordinates over time, it creates a more natural flow.</p>
<h2>2. Normal vector generation based on heightmap</h2>

    <span class="hljs-keyword">return</span> <span class="hljs-title function_">vec4f</span>(color, <span class="hljs-number">1.0</span>);
}


fn <span class="hljs-title function_">blinnPhong</span>(<span class="hljs-attr">material</span>:<span class="hljs-title class_">Material</span>, <span class="hljs-attr">light_strength</span>: vec3&lt;f32&gt;, <span class="hljs-attr">light_vec</span>: vec3&lt;f32&gt;, <span class="hljs-attr">normal</span>: vec3&lt;f32&gt;, <span class="hljs-attr">to_eye</span>: vec3&lt;f32&gt;) -&gt; vec3&lt;f32&gt; {
    <span class="hljs-keyword">let</span> halfway = <span class="hljs-title function_">normalize</span>(to_eye + light_vec);
    <span class="hljs-keyword">let</span> hdotn = <span class="hljs-title function_">dot</span>(halfway, normal);
    <span class="hljs-keyword">let</span> specular = material.<span class="hljs-property">specular</span> * <span class="hljs-title function_">pow</span>(<span class="hljs-title function_">max</span>(hdotn, <span class="hljs-number">0.0</span>), material.<span class="hljs-property">shininess</span>);
    <span class="hljs-keyword">return</span> material.<span class="hljs-property">ambient</span> + (material.<span class="hljs-property">diffuse</span> + specular) * light_strength;
}

fn <span class="hljs-title function_">computeDirectionalLight</span>(<span class="hljs-attr">light</span>:<span class="hljs-title class_">Light</span>, <span class="hljs-attr">material</span>:<span class="hljs-title class_">Material</span>, <span class="hljs-attr">normal</span>: vec3&lt;f32&gt;, <span class="hljs-attr">to_eye</span>: vec3&lt;f32&gt;) -&gt; vec3&lt;f32&gt; {
    <span class="hljs-keyword">let</span> light_vec = -light.<span class="hljs-property">direction</span>;
    <span class="hljs-keyword">let</span> ndotl = <span class="hljs-title function_">max</span>(<span class="hljs-title function_">dot</span>(light_vec, normal), <span class="hljs-number">0.0</span>);
    <span class="hljs-keyword">let</span> light_strength = <span class="hljs-title function_">vec3f</span>(light.<span class="hljs-property">strength</span>) * ndotl;

    <span class="hljs-keyword">return</span> <span class="hljs-title function_">blinnPhong</span>(material, light_strength, light_vec, normal, to_eye);
}</code></pre><p>Color noise was used to blend two colors, creating a more natural texture. In the Vertex Shader, world-space normals were utilized to add shading with Blinn-Phong shading. Additionally, to account for the fact that lower heights in the terrain indicate valleys where light is less likely to reach, the height value was raised to a power and used for ambient occlusion.</p>

<p>Through this project, I learned how to generate terrain based on Perlin noise and render it visually appealingly using WebGPU. By utilizing normal vectors and ambient occlusion, I was able to realistically depict the terrain's depth and lighting effects. The powerful performance of WebGPU enabled high-resolution rendering.</p>
