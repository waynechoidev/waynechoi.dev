<h2>1. PBR Textures</h2>
<p>PBR (Physically Based Rendering) textures are used to describe the physical properties of materials. Typically, a combination of various texture maps is used to compose a single PBR material. There are several types of textures commonly used, primarily including:</p>
<ul>
<li><p>Albedo Map</p>
<p>It represents the base color of the surface, indicating the material's actual color.</p>
</li>
<li><p>Normal Map</p>
<p>It manipulates the surface's normal vectors to add three-dimensional detail, simulating irregular shapes or textures.</p>
</li>
<li><p>Metallic Map</p>
<p>It indicates whether the surface is metallic or non-metallic. It ranges from black (non-metallic) to white (metallic).</p>
</li>
<li><p>Roughness Map</p>
<p>It represents the roughness or smoothness of the surface. It ranges from black (smooth) to white (rough).</p>
</li>
<li><p>Ambient Occlusion Map (AO Map)</p>
<p>It simulates indirect lighting by considering occlusion of the surface. Darker areas in the texture typically represent surface occlusion or concavities.</p>
</li>
<li><p>Height Map</p>
<p>It represents the three-dimensional detail of a surface. It is mainly employed to provide finer details on the surface of objects. Although not covered in <a href="https://learnopengl.com/" class="md-link" target="_blank" rel="noopener noreferrer">Learn OpenGL</a> (presumably because it is unrelated to lighting), it is included in most PBR textures.</p>
</li>
</ul>
<p>To use these textures, a normal vector is required. The normal vector indicates the direction of the surface and plays a crucial role in determining the surface's lighting reflection properties based on the lighting and viewpoint between the light source and observer.</p>
<p>Normal vectors are primarily represented through normal maps, with each pixel of the texture representing the local direction of the surface. This information is used in lighting models considering the directions of the light source and observer. For instance, normal vectors provide the angle between the surface and light, allowing for the simulation of highlights and shadows.</p>
<p>Normal maps are commonly used in tangent space. Tangent space defines the local coordinate space of the surface, with basis vectors representing the normal, tangent, and binormal at each point on the surface. Normal maps are stored in this tangent space, facilitating the easy transformation of normals from texture space.</p>
<p>Therefore, to use a normal map, tangent vectors and normal vectors associated with the surface's local coordinate space are required. This information enables the mapping of normals stored in the normal map to the actual normals of the surface.</p>
<p>While the LearnOpenGL example attempted to calculate tangent vectors using gradients of WorldPos and TexCoords, this method is an inaccurate estimation. Typically, tangent vectors are provided along with the model, so I passed tangent vectors from the CPU to the vertices.</p>
<pre><code class="hljs language-glsl"><span class="hljs-comment">// the code used in [Learn OpenGL](https://learnopengl.com/) to calculate tangents</span>

<span class="hljs-type">vec3</span> Q1  = <span class="hljs-built_in">dFdx</span>(WorldPos);
<span class="hljs-type">vec3</span> Q2  = <span class="hljs-built_in">dFdy</span>(WorldPos);
<span class="hljs-type">vec2</span> st1 = <span class="hljs-built_in">dFdx</span>(TexCoords);
<span class="hljs-type">vec2</span> st2 = <span class="hljs-built_in">dFdy</span>(TexCoords);

<span class="hljs-type">vec3</span> T  = <span class="hljs-built_in">normalize</span>(Q1*st2.t - Q2*st1.t);</code></pre><p>The normal and tangent vectors calculated in the vertex shader exist in the local coordinate space of the model. When passing these vectors to the fragment shader, they need to be transformed into world coordinates. To achieve this, the vectors should be transformed using the model transformation matrix to convert them into world coordinates.</p>
<p>Typically, the transformation of the tangent vector involves only the model transformation matrix. However, for the normal vector, relying solely on the model transformation may not yield correct results when the normal is defined in a non-standard texture coordinate space. This is because the normal vector represents direction, and transformation matrices only preserve length and rotation, not direction.</p>
<p>Therefore, for the normal vector, it's necessary to use the transpose and inverse of the model transformation matrix for the correct transformation into world coordinates. This ensures that the normal vector is accurately transformed into world coordinates. The reason for using transpose and inverse is to ensure preservation of direction during the transformation, as these operations are used to perform transformations that preserve direction. You can find more detailed explanations at this <a href="https://paroj.github.io/gltut/Illumination/Tut09%20Normal%20Transformation.html" class="md-link" target="_blank" rel="noopener noreferrer">link</a>.</p>
<pre><code class="hljs language-glsl"><span class="hljs-comment">// the code for calculating the normal world and tangent world vectors in the vertex shader</span>

<span class="hljs-type">vec3</span> normalWorld = <span class="hljs-built_in">normalize</span>(<span class="hljs-type">mat3</span>(<span class="hljs-built_in">transpose</span>(<span class="hljs-built_in">inverse</span>(model))) * norm);
<span class="hljs-type">vec3</span> tangentWorld = <span class="hljs-built_in">normalize</span>(model * <span class="hljs-type">vec4</span>(tangent, <span class="hljs-number">1.0</span>)).xyz;</code></pre><p>First, we apply the height map in the Vertex shader. This texture directly manipulates texture coordinates to implement the three-dimensional shape of the surface, rather than affecting lighting or shadows.</p>
<pre><code class="hljs language-glsl"><span class="hljs-keyword">uniform</span> <span class="hljs-type">sampler2D</span> heightTex;

<span class="hljs-type">float</span> height = <span class="hljs-built_in">texture</span>(heightTex, tex).r;
height = height * <span class="hljs-number">2.0</span> - <span class="hljs-number">1.0</span>; <span class="hljs-comment">// 0~1 -&gt; -1~1</span>
<span class="hljs-type">vec3</span> newPos = position + <span class="hljs-type">vec3</span>(normalWorld * height);</code></pre><p>All remaining textures are related to lighting, and we'll cover them from the next chapter onward.</p>

<h2>2. Direct Lighting</h2>
<p>Direct Lighting is one of the crucial concepts in Physically Based Rendering (PBR). It deals with scenarios where light directly reflects off an object's surface. In other words, it models the process where light travels in a straight line from the light source to the object, determining aspects like the object's color and shadows. Typically, the Bidirectional Reflectance Distribution Function (BRDF) is used for these calculations. Here, we'll implement it using the widely adopted Cook-Torrance model. This model considers the microstructure of the object's surface and the angle of incidence of light to provide realistic lighting effects. In this explanation, rather than delving into the microfacet theory that deals with fine surface structures, we'll focus on implementing the function. You can find more detailed theoretical information on this topic in this <a href="https://blog.selfshadow.com/publications/s2013-shading-course/hoffman/s2013_pbs_physics_math_slides.pdf" class="md-link" target="_blank" rel="noopener noreferrer">link</a>.</p>
<blockquote>
<h4>Microfacet BRDF</h4>
<p>f(l,v) = F(l, h) G(l, v, h) D(h) / 4(n · l)(n · v)</p>
</blockquote>
<p>The equation represents the general form of the BRDF (Bidirectional Reflectance Distribution Function). I'll provide explanations and implementations for each component.</p>
<h3>F (Fresnel Reflectance)</h3>
<blockquote>
<p>F(Cspec, l, h) = Cspec + (1 - Cspec)(1 - (l · h)) ^ 5</p>
</blockquote>
<p>Fresnel Reflectance represents the optical properties when light reaches and reflects off the surface.</p>
<pre><code class="hljs language-glsl"><span class="hljs-keyword">uniform</span> <span class="hljs-type">sampler2D</span> albedoMap;
<span class="hljs-keyword">uniform</span> <span class="hljs-type">sampler2D</span> metallicMap;

<span class="hljs-comment">// Apply gamma correction to the sampled albedo texture to convert it from sRGB space to linear space</span>
<span class="hljs-type">vec3</span> albedo = <span class="hljs-built_in">pow</span>(<span class="hljs-built_in">texture</span>(albedoMap, TexCoord).rgb, <span class="hljs-type">vec3</span>(<span class="hljs-number">2.2</span>));
<span class="hljs-type">float</span> metallic  = <span class="hljs-built_in">texture</span>(metallicMap, TexCoord).r;

<span class="hljs-type">vec3</span> fresnelSchlick(<span class="hljs-type">float</span> cosTheta, <span class="hljs-type">vec3</span> F0)
{
    <span class="hljs-keyword">return</span> F0 + (<span class="hljs-number">1.0</span> - F0) * <span class="hljs-built_in">pow</span>(<span class="hljs-built_in">clamp</span>(<span class="hljs-number">1.0</span> - cosTheta, <span class="hljs-number">0.0</span>, <span class="hljs-number">1.0</span>), <span class="hljs-number">5.0</span>);
}

<span class="hljs-comment">// Initialize the surface reflectance coefficient F0 with a default value</span>
<span class="hljs-type">vec3</span> F0 = <span class="hljs-type">vec3</span>(<span class="hljs-number">0.04</span>);

<span class="hljs-comment">// Linearly interpolate between the surface reflectance coefficient F0 and the albedo (surface color) based on metallic value</span>
F0 = <span class="hljs-built_in">mix</span>(F0, albedo, metallic);

<span class="hljs-type">vec3</span> F = fresnelSchlick(<span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(H, V), <span class="hljs-number">0.0</span>), F0);</code></pre><h3>G (Geometry Factor)</h3>
<blockquote>
<p>GSchlickGGX(n, v, k) = n ⋅ v ( n ⋅ v) (1 − k) + k</p>
<p>G(l, v, h) = Gs1(l, h) Gs2(v, h)</p>
</blockquote>
<p>Geometry Factor indicates the portions occluded between the light and the observer, modeling effects such as occluded shadows. it takes a material's roughness parameter as input with rougher surfaces having a higher probability of overshadowing microfacets. The geometry function we will use is a combination of the GGX and Schlick-Beckmann approximation known as Schlick-GGX.</p>
<pre><code class="hljs language-glsl"><span class="hljs-keyword">uniform</span> <span class="hljs-type">sampler2D</span> roughnessMap;
<span class="hljs-keyword">uniform</span> <span class="hljs-type">sampler2D</span> normalMap;

<span class="hljs-keyword">uniform</span> <span class="hljs-type">vec3</span> camPos;

<span class="hljs-type">float</span> roughness = <span class="hljs-built_in">texture</span>(roughnessMap, TexCoord).r;

<span class="hljs-type">vec3</span> N = <span class="hljs-built_in">normalize</span>(normalWorld);
<span class="hljs-comment">// Adjust the tangent vector to ensure it is perpendicular to the surface</span>
<span class="hljs-comment">// by removing the component parallel to the normal vector.</span>
<span class="hljs-type">vec3</span> T = <span class="hljs-built_in">normalize</span>(tangentWorld - <span class="hljs-built_in">dot</span>(tangentWorld, N) * N);
<span class="hljs-type">vec3</span> B = <span class="hljs-built_in">cross</span>(N, T);

<span class="hljs-comment">// Create a TBN matrix containing the tangent, binormal, and normal vectors.</span>
<span class="hljs-type">mat3</span> TBN = <span class="hljs-type">mat3</span>(T, B, N);

<span class="hljs-comment">// Sample the normal map from the texture and map it to the [-1, 1] range to update the normal vector.</span>
N = <span class="hljs-built_in">normalize</span>(TBN * (<span class="hljs-built_in">texture</span>(normalMap, TexCoord).xyz * <span class="hljs-number">2.0</span> - <span class="hljs-number">1.0</span>));

<span class="hljs-comment">// Compute the view vector.</span>
<span class="hljs-type">vec3</span> V = <span class="hljs-built_in">normalize</span>(camPos - posWorld);

<span class="hljs-comment">// Compute the light direction vector</span>
<span class="hljs-type">vec3</span> L = <span class="hljs-built_in">normalize</span>(lightPos - posWorld);

<span class="hljs-type">float</span> GeometrySchlickGGX(<span class="hljs-type">float</span> NdotV, <span class="hljs-type">float</span> roughness)
{
    <span class="hljs-type">float</span> r = (roughness + <span class="hljs-number">1.0</span>);
    <span class="hljs-type">float</span> k = (r * r) / <span class="hljs-number">8.0</span>;

    <span class="hljs-type">float</span> nom   = NdotV;
    <span class="hljs-type">float</span> denom = NdotV * (<span class="hljs-number">1.0</span> - k) + k;

    <span class="hljs-keyword">return</span> nom / denom;
}

<span class="hljs-type">float</span> GeometrySmith(<span class="hljs-type">vec3</span> N, <span class="hljs-type">vec3</span> V, <span class="hljs-type">vec3</span> L, <span class="hljs-type">float</span> roughness)
{
    <span class="hljs-type">float</span> NdotV = <span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(N, V), <span class="hljs-number">0.0</span>);
    <span class="hljs-type">float</span> NdotL = <span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(N, L), <span class="hljs-number">0.0</span>);
    <span class="hljs-type">float</span> ggx2 = GeometrySchlickGGX(NdotV, roughness);
    <span class="hljs-type">float</span> ggx1 = GeometrySchlickGGX(NdotL, roughness);

    <span class="hljs-keyword">return</span> ggx1 * ggx2;
}

<span class="hljs-type">float</span> G = GeometrySmith(N, V, L, roughness);</code></pre><h3>D (Normal Distribution Function)</h3>
<blockquote>
<p>NDF(n, h, α) = α ^ 2 / π((n ⋅ h) ^ 2 (α ^ 2 − 1) + 1) ^ 2</p>
</blockquote>
<p>Normal Distribution Function denotes the reflection direction due to the microstructure of the surface, considering surface roughness or fine surface characteristics. The NDF function we'll be using is known as the Trowbridge-Reitz GGX.</p>
<pre><code class="hljs language-glsl"><span class="hljs-type">float</span> DistributionGGX(<span class="hljs-type">vec3</span> N, <span class="hljs-type">vec3</span> H, <span class="hljs-type">float</span> roughness)
{
    <span class="hljs-type">float</span> a = roughness*roughness;
    <span class="hljs-type">float</span> a2 = a*a;
    <span class="hljs-type">float</span> NdotH = <span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(N, H), <span class="hljs-number">0.0</span>);
    <span class="hljs-type">float</span> NdotH2 = NdotH*NdotH;

    <span class="hljs-type">float</span> nom   = a2;
    <span class="hljs-type">float</span> denom = (NdotH2 * (a2 - <span class="hljs-number">1.0</span>) + <span class="hljs-number">1.0</span>);
    denom = PI * denom * denom;

    <span class="hljs-keyword">return</span> nom / denom;
}

<span class="hljs-type">float</span> NDF = DistributionGGX(N, H, roughness);</code></pre><h3>BRDF</h3>
<pre><code class="hljs language-glsl"><span class="hljs-type">vec3</span> numerator = NDF * G * F;
<span class="hljs-comment">// + 0.0001 to prevent divide by zero</span>
<span class="hljs-type">float</span> denominator = <span class="hljs-number">4.0</span> * <span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(N, V), <span class="hljs-number">0.0</span>) * <span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(N, L), <span class="hljs-number">0.0</span>) + <span class="hljs-number">0.0001</span>;

<span class="hljs-type">vec3</span> BRDF = numerator / denominator;</code></pre><p>Now we can finally calculate this direct light's contribution to the reflectance equation.</p>
<p>In the <a href="https://learnopengl.com/" class="md-link" target="_blank" rel="noopener noreferrer">Learn OpenGL</a> example, they used point lights coming from four directions, but I only used one point light.</p>
<pre><code class="hljs language-glsl"><span class="hljs-comment">// Calculate the specular reflection coefficient.</span>
<span class="hljs-type">vec3</span> kS = F;

<span class="hljs-comment">// Calculate the diffuse reflection coefficient.</span>
<span class="hljs-type">vec3</span> kD = <span class="hljs-type">vec3</span>(<span class="hljs-number">1.0</span>) - kS;
kD *= <span class="hljs-number">1.0</span> - metallic;

<span class="hljs-comment">// Scale the light intensity by the cosine of the angle between the normal vector and the light direction.</span>
<span class="hljs-type">float</span> NdotL = <span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(N, L), <span class="hljs-number">0.0</span>);

<span class="hljs-comment">// Calculate the direct lighting contribution, combining diffuse and specular reflections.</span>
<span class="hljs-type">vec3</span> directLight = (kD * albedo / PI + BRDF) * radiance * NdotL;</code></pre><hr />
<h2>3. Environment Lighting</h2>
<p>Environment Lighting is primarily implemented using the IBL (Image-Based Lighting) technique. This method involves representing the surrounding environment with appropriate maps and using these maps to calculate lighting for objects. To implement Environment Lighting for PBR (Physically Based Rendering), three main textures are required: the Irradiance Map, Specular Map, and BRDF Texture.</p>
<h3>Irradiance Map</h3>
<p>Irradiance Map is used to model the lighting of the surrounding environment. It represents the incoming radiance at a specific point, typically captured and generated around the camera's surroundings. Irradiance Map is utilized to simulate indirect lighting on the surface of objects, thus determining their color and brightness.</p>
<p>In <a href="https://learnopengl.com/" class="md-link" target="_blank" rel="noopener noreferrer">Learn OpenGL</a>, the environment map is sampled using point sampling in a spherical coordinate system. As the desired results weren't achieved with this method, I opted for importance sampling to sample the Irradiance Map from the environment map. This approach involves sampling the more important areas of the environment map more frequently to obtain a more accurate Irradiance value. To implement this, I referred to the code of an open-source project called <a href="https://www.derkreature.com/iblbaker" class="md-link" target="_blank" rel="noopener noreferrer">IBL Baker</a> extensively.</p>
<pre><code class="hljs language-glsl"><span class="hljs-meta">#version 420 core</span>

<span class="hljs-keyword">out</span> <span class="hljs-type">vec4</span> FragColor;

<span class="hljs-keyword">in</span> <span class="hljs-type">vec3</span> WorldPos;

<span class="hljs-type">vec3</span> rescaleHDR(<span class="hljs-type">vec3</span> hdrPixel) {
    hdrPixel = hdrPixel / (hdrPixel + <span class="hljs-type">vec3</span>(<span class="hljs-number">1.0</span>));

    <span class="hljs-keyword">if</span> (hdrPixel.x &lt; <span class="hljs-number">0.0</span>)
        hdrPixel.x = <span class="hljs-number">0.0</span>;
    <span class="hljs-keyword">if</span> (hdrPixel.y &lt; <span class="hljs-number">0.0</span>)
        hdrPixel.y = <span class="hljs-number">0.0</span>;
    <span class="hljs-keyword">if</span> (hdrPixel.z &lt; <span class="hljs-number">0.0</span>)
        hdrPixel.z = <span class="hljs-number">0.0</span>;

    <span class="hljs-type">float</span> intensity = <span class="hljs-built_in">dot</span>(hdrPixel, <span class="hljs-type">vec3</span>(<span class="hljs-number">0.299</span>, <span class="hljs-number">0.587</span>, <span class="hljs-number">0.114</span>));

    <span class="hljs-comment">// Saturation adjustment</span>
    hdrPixel = <span class="hljs-built_in">mix</span>(intensity.xxx, hdrPixel, IBLCorrection.y);

    <span class="hljs-comment">// Hue adjustment</span>
    <span class="hljs-type">vec3</span> root3 = <span class="hljs-type">vec3</span>(<span class="hljs-number">0.57735</span>, <span class="hljs-number">0.57735</span>, <span class="hljs-number">0.57735</span>);
    <span class="hljs-type">float</span> half_angle = <span class="hljs-number">0.5</span> * <span class="hljs-built_in">radians</span>(IBLCorrection.z);
    <span class="hljs-type">vec4</span> rot_quat = <span class="hljs-type">vec4</span>(root3 * <span class="hljs-built_in">sin</span>(half_angle), <span class="hljs-built_in">cos</span>(half_angle));
    <span class="hljs-type">mat3</span> rot_Matrix = <span class="hljs-type">mat3</span>(
        <span class="hljs-type">vec3</span>(<span class="hljs-number">1.0</span> - <span class="hljs-number">2.0</span> * (rot_quat.y * rot_quat.y + rot_quat.z * rot_quat.z), <span class="hljs-number">2.0</span> * (rot_quat.x * rot_quat.y - rot_quat.w * rot_quat.z), <span class="hljs-number">2.0</span> * (rot_quat.x * rot_quat.z + rot_quat.w * rot_quat.y)),
        <span class="hljs-type">vec3</span>(<span class="hljs-number">2.0</span> * (rot_quat.x * rot_quat.y + rot_quat.w * rot_quat.z), <span class="hljs-number">1.0</span> - <span class="hljs-number">2.0</span> * (rot_quat.x * rot_quat.x + rot_quat.z * rot_quat.z), <span class="hljs-number">2.0</span> * (rot_quat.y * rot_quat.z - rot_quat.w * rot_quat.x)),
        <span class="hljs-type">vec3</span>(<span class="hljs-number">2.0</span> * (rot_quat.x * rot_quat.z - rot_quat.w * rot_quat.y), <span class="hljs-number">2.0</span> * (rot_quat.y * rot_quat.z + rot_quat.w * rot_quat.x), <span class="hljs-number">1.0</span> - <span class="hljs-number">2.0</span> * (rot_quat.x * rot_quat.x + rot_quat.y * rot_quat.y))
    );
    hdrPixel = <span class="hljs-type">mat3</span>(rot_Matrix) * hdrPixel;

    hdrPixel *= EnvironmentScale;
    <span class="hljs-keyword">return</span> hdrPixel;
}

<span class="hljs-type">vec2</span> Hammersley(<span class="hljs-type">uint</span> i, <span class="hljs-type">uint</span> N) {
    <span class="hljs-type">uint</span> bits = (i &lt;&lt; <span class="hljs-number">16</span>u) | (i &gt;&gt; <span class="hljs-number">16</span>u);
    bits = ((bits &amp; <span class="hljs-number">0x55555555</span>u) &lt;&lt; <span class="hljs-number">1</span>u) | ((bits &amp; <span class="hljs-number">0xAAAAAAAA</span>u) &gt;&gt; <span class="hljs-number">1</span>u);
    bits = ((bits &amp; <span class="hljs-number">0x33333333</span>u) &lt;&lt; <span class="hljs-number">2</span>u) | ((bits &amp; <span class="hljs-number">0xCCCCCCCC</span>u) &gt;&gt; <span class="hljs-number">2</span>u);
    bits = ((bits &amp; <span class="hljs-number">0x0F0F0F0F</span>u) &lt;&lt; <span class="hljs-number">4</span>u) | ((bits &amp; <span class="hljs-number">0xF0F0F0F0</span>u) &gt;&gt; <span class="hljs-number">4</span>u);
    bits = ((bits &amp; <span class="hljs-number">0x00FF00FF</span>u) &lt;&lt; <span class="hljs-number">8</span>u) | ((bits &amp; <span class="hljs-number">0xFF00FF00</span>u) &gt;&gt; <span class="hljs-number">8</span>u);
    <span class="hljs-type">float</span> rdi = <span class="hljs-type">float</span>(bits) * <span class="hljs-number">2.3283064365386963e-10</span>;
    <span class="hljs-keyword">return</span> <span class="hljs-type">vec2</span>(<span class="hljs-type">float</span>(i) / <span class="hljs-type">float</span>(N), rdi);

<span class="hljs-type">vec3</span> importanceSampleGGX(<span class="hljs-type">vec2</span> Xi, <span class="hljs-type">float</span> roughness, <span class="hljs-type">vec3</span> N) {
    <span class="hljs-type">float</span> a = roughness * roughness;
    <span class="hljs-type">float</span> Phi = <span class="hljs-number">2.0</span> * PI * Xi.x;
    <span class="hljs-type">float</span> CosTheta = <span class="hljs-built_in">sqrt</span>((<span class="hljs-number">1.0</span> - Xi.y) / (<span class="hljs-number">1.0</span> + (a * a - <span class="hljs-number">1.0</span>) * Xi.y));
    <span class="hljs-type">float</span> SinTheta = <span class="hljs-built_in">sqrt</span>(<span class="hljs-number">1.0</span> - CosTheta * CosTheta);
    <span class="hljs-type">vec3</span> H;
    H.x = SinTheta * <span class="hljs-built_in">cos</span>(Phi);
    H.y = SinTheta * <span class="hljs-built_in">sin</span>(Phi);
    H.z = CosTheta;
    <span class="hljs-type">vec3</span> UpVector = <span class="hljs-built_in">abs</span>(N.z) &lt; <span class="hljs-number">0.999</span> ? <span class="hljs-type">vec3</span>(<span class="hljs-number">0</span>, <span class="hljs-number">0</span>, <span class="hljs-number">1</span>) : <span class="hljs-type">vec3</span>(<span class="hljs-number">1</span>, <span class="hljs-number">0</span>, <span class="hljs-number">0</span>);
    <span class="hljs-type">vec3</span> TangentX = <span class="hljs-built_in">normalize</span>(<span class="hljs-built_in">cross</span>(UpVector, N));
    <span class="hljs-type">vec3</span> TangentY = <span class="hljs-built_in">cross</span>(N, TangentX);
    <span class="hljs-keyword">return</span> TangentX * H.x + TangentY * H.y + N * H.z;
}

<span class="hljs-type">float</span> specularD(<span class="hljs-type">float</span> roughness, <span class="hljs-type">float</span> NoH) {
    <span class="hljs-type">float</span> a2 = roughness * roughness;
    <span class="hljs-type">float</span> d = (NoH * a2 - NoH) * NoH + <span class="hljs-number">1.0</span>;
    <span class="hljs-keyword">return</span> a2 / (PI * d * d);
}

<span class="hljs-type">vec4</span> sumSpecular(<span class="hljs-type">vec3</span> spec, <span class="hljs-type">float</span> NoL, <span class="hljs-type">vec4</span> result) {
    result.xyz += spec;
    result.w += NoL;
    <span class="hljs-keyword">return</span> result;
}

<span class="hljs-type">vec3</span> ImportanceSample(<span class="hljs-type">vec3</span> R) {
    <span class="hljs-type">vec3</span> N = <span class="hljs-built_in">normalize</span>(R);
    <span class="hljs-type">vec3</span> V = <span class="hljs-built_in">normalize</span>(R);
    <span class="hljs-type">vec4</span> result = <span class="hljs-type">vec4</span>(<span class="hljs-number">0.0</span>);

    <span class="hljs-type">float</span> sampleStep = <span class="hljs-type">float</span>(ConvolutionMaxSamples) / <span class="hljs-type">float</span>(ConvolutionSampleCount);
    <span class="hljs-type">uint</span> sampleId = <span class="hljs-type">uint</span>(ConvolutionSamplesOffset);

    <span class="hljs-type">int</span> cubeWidth = <span class="hljs-built_in">textureSize</span>(envCubemap, <span class="hljs-number">0</span>).x;

    <span class="hljs-keyword">for</span> (<span class="hljs-type">int</span> i = <span class="hljs-number">0</span>; i &lt; ConvolutionSampleCount; i++) {
        <span class="hljs-type">vec2</span> Xi = Hammersley(sampleId, <span class="hljs-type">uint</span>(ConvolutionMaxSamples));

        <span class="hljs-type">vec3</span> H = importanceSampleGGX(Xi, ConvolutionRoughness, N);
        <span class="hljs-type">vec3</span> L = <span class="hljs-number">2.0</span> * <span class="hljs-built_in">dot</span>(V, H) * H - V;
        <span class="hljs-type">float</span> NoL = <span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(N, L), <span class="hljs-number">0.0</span>);
        <span class="hljs-type">float</span> VoL = <span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(V, L), <span class="hljs-number">0.0</span>);
        <span class="hljs-type">float</span> NoH = <span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(N, H), <span class="hljs-number">0.0</span>);
        <span class="hljs-type">float</span> VoH = <span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(V, H), <span class="hljs-number">0.0</span>);
        <span class="hljs-keyword">if</span> (NoL &gt; <span class="hljs-number">0.0</span>) {
            <span class="hljs-type">float</span> Dh = specularD(ConvolutionRoughness, NoH);
            <span class="hljs-type">float</span> pdf = Dh * NoH / (<span class="hljs-number">4.0</span> * VoH);
            <span class="hljs-type">float</span> solidAngleTexel = <span class="hljs-number">4.0</span> * PI / (<span class="hljs-number">6.0</span> * cubeWidth * cubeWidth);
            <span class="hljs-type">float</span> solidAngleSample = <span class="hljs-number">1.0</span> / (ConvolutionSampleCount * pdf);
            <span class="hljs-type">float</span> lod = ConvolutionRoughness == <span class="hljs-number">0.0</span> ? <span class="hljs-number">0.0</span> : <span class="hljs-number">0.5</span> * <span class="hljs-built_in">log2</span>(solidAngleSample / solidAngleTexel);

            <span class="hljs-type">vec3</span> hdrPixel = rescaleHDR(<span class="hljs-built_in">textureLod</span>(envCubemap, L, lod).rgb);
            <span class="hljs-comment">// vec3 hdrPixel = textureLod(envCubemap, L, lod).rgb;</span>
            result = sumSpecular(hdrPixel, NoL, result);
        }
        sampleId += <span class="hljs-type">uint</span>(sampleStep);
    }

    <span class="hljs-keyword">if</span> (result.w == <span class="hljs-number">0.0</span>)
        <span class="hljs-keyword">return</span> result.xyz;
    <span class="hljs-keyword">else</span>
        <span class="hljs-keyword">return</span> result.xyz / result.w;
}

    <span class="hljs-keyword">if</span> (ConvolutionSamplesOffset &gt;= <span class="hljs-number">1</span>) {

<p>We are going to implement specular using an environment map, a BRDF texture, and mipmaps.</p>
<h3>BRDF Texture</h3>
<p>The BRDF (Bidirectional Reflectance Distribution Function) texture is used to define the surface properties of an object. This texture is composed of a function that represents how light is reflected from the surface of the object, indicating the direction and amount of reflection. In other words, it determines how light coming from a certain direction is reflected in various directions from the surface. The BRDF texture is used to define properties such as surface roughness, glossiness, and reflection characteristics.</p>
<p>In environment lighting, the BRDF texture is primarily used to model the interaction of light reflection on the surface of an object. This texture determines how light is reflected from the surface of the object depending on its properties when the light reaches the surface, thus making the appearance of the object more realistic.</p>
<p>For example, when the surface of an object is rough and lacks glossiness, the BRDF texture can accurately model how light is reflected from the surface of the object. This allows for a more accurate simulation of how light generated from environment lighting is reflected from the surface of the object.</p>
<p>Here, the code for generating the BRDF texture from the Environment Map was directly borrowed from <a href="https://learnopengl.com/" class="md-link" target="_blank" rel="noopener noreferrer">Learn OpenGL</a>.</p>

<span class="hljs-type">vec2</span> IntegrateBRDF(<span class="hljs-type">float</span> NdotV, <span class="hljs-type">float</span> roughness)
{

    V.y = <span class="hljs-number">0.0</span>;
    V.z = NdotV;

    <span class="hljs-type">float</span> A = <span class="hljs-number">0.0</span>;
    <span class="hljs-type">float</span> B = <span class="hljs-number">0.0</span>;

    <span class="hljs-type">vec3</span> N = <span class="hljs-type">vec3</span>(<span class="hljs-number">0.0</span>, <span class="hljs-number">0.0</span>, <span class="hljs-number">1.0</span>);

    <span class="hljs-keyword">for</span>(<span class="hljs-type">uint</span> i = <span class="hljs-number">0</span>u; i &lt; SAMPLE_COUNT; ++i)

        <span class="hljs-type">float</span> VdotH = <span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(V, H), <span class="hljs-number">0.0</span>);

        <span class="hljs-keyword">if</span>(NdotL &gt; <span class="hljs-number">0.0</span>)

            <span class="hljs-type">float</span> G = GeometrySmith(N, V, L, roughness);
            <span class="hljs-type">float</span> G_Vis = (G * VdotH) / (NdotH * NdotV);
            <span class="hljs-type">float</span> Fc = <span class="hljs-built_in">pow</span>(<span class="hljs-number">1.0</span> - VdotH, <span class="hljs-number">5.0</span>);

            A += (<span class="hljs-number">1.0</span> - Fc) * G_Vis;
            B += Fc * G_Vis;
        }
    }
    A /= <span class="hljs-type">float</span>(SAMPLE_COUNT);
    B /= <span class="hljs-type">float</span>(SAMPLE_COUNT);
    <span class="hljs-keyword">return</span> <span class="hljs-type">vec2</span>(A, B);
}

<span class="hljs-type">void</span> main()
{
    <span class="hljs-type">vec2</span> integratedBRDF = IntegrateBRDF(TexCoords.x, TexCoords.y);
    FragColor = integratedBRDF;
}</code></pre><h3>Ambient Lighting</h3>
<p>Now we calculate indirect lighting using the given textures. Here, we use Image-Based Lighting (IBL) for this purpose.</p>
<p>First, we compute the Fresnel reflection coefficient on the surface. This coefficient determines the ratio of incident light to reflected light and is used in conjunction with the surface roughness.</p>
<pre><code class="hljs language-glsl"><span class="hljs-type">vec3</span> fresnelSchlickRoughness(<span class="hljs-type">float</span> cosTheta, <span class="hljs-type">vec3</span> F0, <span class="hljs-type">float</span> roughness)
{
    <span class="hljs-keyword">return</span> F0 + (<span class="hljs-built_in">max</span>(<span class="hljs-type">vec3</span>(<span class="hljs-number">1.0</span> - roughness), F0) - F0) * <span class="hljs-built_in">pow</span>(<span class="hljs-built_in">clamp</span>(<span class="hljs-number">1.0</span> - cosTheta, <span class="hljs-number">0.0</span>, <span class="hljs-number">1.0</span>), <span class="hljs-number">5.0</span>);
}

<span class="hljs-comment">// ambient lighting (we now use IBL as the ambient term)</span>
<span class="hljs-type">vec3</span> F = fresnelSchlickRoughness(<span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(N, V), <span class="hljs-number">0.0</span>), F0, roughness);</code></pre><p>Based on the Fresnel coefficient, we calculate the Specular and Diffuse coefficients. kS represents the Specular coefficient, while KD represents the Diffuse coefficient. These coefficients are determined based on the surface's metallic property.</p>
<pre><code class="hljs language-glsl"><span class="hljs-type">vec3</span> kS = F;
<span class="hljs-type">vec3</span> kD = <span class="hljs-number">1.0</span> - kS;
kD \*= <span class="hljs-number">1.0</span> - metallic;</code></pre><p>We calculate the surface's environmental lighting using the Irradiance Cubemap. By sampling the Irradiance Cubemap with the surface's normal vector (N), we obtain the diffuse component by multiplying the result with the surface's albedo.</p>
<pre><code class="hljs language-glsl"><span class="hljs-type">vec3</span> irradiance = <span class="hljs-built_in">texture</span>(irradianceCubemap, N).rgb;
<span class="hljs-type">vec3</span> diffuse = irradiance \* albedo;</code></pre><p>We compute the specular component using the Pre-filtered Environment Map and the BRDF Look-Up Table (LUT). The Pre-filtered Environment Map represents the level of reflected environment map details based on the surface's roughness. The BRDF LUT is a precomputed table of BRDF values based on the angle and roughness between the surface's normal vector and the view vector. By combining these, we obtain the specular component.</p>
<pre><code class="hljs language-glsl"><span class="hljs-comment">// sample both the pre-filter map and the BRDF lut and combine them together as per the Split-Sum approximation to get the IBL specular part.</span>
<span class="hljs-keyword">const</span> <span class="hljs-type">float</span> MAX_REFLECTION_LOD = <span class="hljs-number">4.0</span>;
<span class="hljs-type">vec3</span> prefilteredColor = <span class="hljs-built_in">textureLod</span>(preFilteredEnvmap, R, roughness _ MAX_REFLECTION_LOD).rgb;
<span class="hljs-type">vec2</span> brdf = <span class="hljs-built_in">texture</span>(brdfLUT, <span class="hljs-type">vec2</span>(<span class="hljs-built_in">max</span>(<span class="hljs-built_in">dot</span>(N, V), <span class="hljs-number">0.0</span>), roughness)).rg;
specular = prefilteredColor * (F \* brdf.x + brdf.y);</code></pre><p>We combine the diffuse and specular components to compute the overall indirect lighting. We multiply this by the Ambient Occlusion (AO) value to obtain the final indirect lighting.</p>
<pre><code class="hljs language-glsl"><span class="hljs-type">vec3</span> ambient = (kD * diffuse + specular) * ao;</code></pre><hr />
<h2>4. Post Processing</h2>
<h3>HDR Tonemapping</h3>
<p>HDR images represent a wide range of luminance values, requiring proper tonemapping to display them accurately on standard display devices. In this code, Reinhard tonemapping is used to compress the brightness and bring the dynamic range of the image into a suitable range.</p>
<p>Reinhard tonemapping is a method used to compress the dynamic range of high dynamic range (HDR) images so that they can be accurately displayed on low dynamic range (LDR) devices, such as computer monitors and TVs. This technique adjusts the brightness of the pixels in the HDR image based on their luminance values, aiming to maintain natural-looking contrast while preventing overexposure or loss of detail in both shadow and highlight areas.</p>
<h3>Gamma Correction</h3>
<p>HDR operations are performed entirely in linear space. In linear space, adjustments to brightness and color occur linearly, enabling more accurate and predictable calculations. However, most screens and image storage media use gamma-corrected nonlinear spaces. This helps efficiently represent details in bright areas by considering human visual characteristics.</p>
<p>Therefore, before displaying HDR images, they need to be transformed from linear space to nonlinear space through gamma correction. This preserves details in bright areas better and results in a more natural display on the screen.</p>
<pre><code class="hljs language-glsl"><span class="hljs-type">vec3</span> color = directLight + ambient;

<span class="hljs-comment">// HDR tonemapping</span>
color = color / (color + <span class="hljs-type">vec3</span>(<span class="hljs-number">1.0</span>));

<span class="hljs-comment">// gamma correct</span>
color = <span class="hljs-built_in">pow</span>(color, <span class="hljs-type">vec3</span>(<span class="hljs-number">1.0</span>/<span class="hljs-number">2.2</span>));</code></pre><hr />
<h2>5. WebGL</h2>
<p>I've migrated the code implemented in OpenGL to WebGL. However, dynamically implementing IBL textures like in the native environment was cumbersome, and there were difficulties in loading HDRI textures. So, I decided to first create a native texture generation app called "IBL Maker" to generate textures in advance. Then, I used those textures in WebGL to implement PBR.</p>
<p>Since I saved the textures in JPG format, I had to pay attention to gamma correction when saving textures in OpenGL and loading textures in WebGL, unlike in the native environment.</p>
